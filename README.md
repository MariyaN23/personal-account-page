# Личный кабинет клиента

## Описание

Страница личного кабинета клиента с таблицей объявлений и боковой панелью уведомлений.


## Функционал
1) Главная страница с информацией о профиле и таблицей устройств
3) Таблица:
   -  При нажатии на чекбокс открывается всплывающее окно с выбором действий (реализовано на десктопах): опубликовать, на паузу, удалить
   -  При нажатии на три точки (десктоп) / кнопку "Изменить" (мобильные) меню с выбором действий: на паузу, изменить, удалить
4) Модальное окно при нажатии на "Добавить новое", при открытии - форма с валидацией пустых значений
